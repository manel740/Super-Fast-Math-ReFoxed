# Fast Math — NeoForge

A NeoForge port of **Fast Math**, an optimization mod originally created by **EliasB**.

Fast Math is designed to improve mathematical operations used by Minecraft, reducing computational overhead in areas where these calculations are performed frequently.

> **This repository is a NeoForge port. The original Fast Math mod was created by EliasB.**

## ✨ Features

* Optimized mathematical operations.
* Reduced computational overhead for supported math operations.
* Designed for performance-focused Minecraft installations.
* Native NeoForge integration.
* Lightweight and focused on optimization.

## 📦 Supported Versions

| Minecraft | Loader   | Status      |
| --------- | -------- | ----------- |
| 1.21.1    | NeoForge | ✅ Supported |

## 🔧 Installation

1. Install **Minecraft 1.21.1**.
2. Install the appropriate **NeoForge** version.
3. Download the latest Fast Math NeoForge `.jar`.
4. Place the `.jar` file inside your Minecraft `mods` folder.
5. Launch Minecraft using the NeoForge profile.

## ⚙️ Compatibility

Fast Math is intended to work alongside other performance and optimization mods.

However, compatibility may vary depending on the Minecraft version, NeoForge version, and other mods installed.

If you encounter an issue, please provide:

* Minecraft version
* NeoForge version
* Fast Math version
* Other installed mods
* Complete crash report or relevant log

## 🛠️ Development

This project is built for **NeoForge** using **Java 21**.

The project was ported from the original Fast Math implementation while adapting the necessary Minecraft and loader-specific components for NeoForge.

### Building from source

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
cd YOUR_REPOSITORY
```

Build the mod with Gradle:

```bash
./gradlew build
```

On Windows:

```powershell
.\gradlew.bat build
```

The compiled `.jar` will be generated in:

```text
build/libs/
```
